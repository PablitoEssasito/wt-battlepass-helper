# WT Battlepass Helper

A practical calculator for War Thunder Battle Pass progress. Enter your current
progress, login count, challenges and available special tasks to see which level
is still reachable before the season ends.

## Development

```bash
npm install
npm run dev
```

Run checks with:

```bash
npm test -- --run
npm run build
```
